# 🧙 PotterWiki

PotterWiki é uma enciclopédia digital interativa baseada no universo de Harry Potter. O projeto consome uma API pública para exibir informações de personagens, casas e varinhas de forma simples, responsiva e organizada.

## 🔍 Funcionalidades

- Listagem de personagens, casas e varinhas
- Visualização de detalhes ao clicar em cada item
- Interface leve e responsiva
- Consumo de API REST com tratamento de dados

## 🛠️ Tecnologias

- React
- JavaScript
- HTML5 & CSS3
- API REST pública

## 🚀 Como executar

```bash
# Clone o repositório
git clone https://github.com/richwrd/PotterWiki

# Acesse a pasta do projeto
cd PotterWiki

# Instale as dependências
npm install

# Inicie o projeto
npm start
